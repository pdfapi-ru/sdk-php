# Изменения

## 0.1.0

Первая версия: `html`, `url`, `markdown`, `office`, `officeFromString`, `convert`, `me`; параметры страницы — именованными аргументами; исключения по кодам API; повторы при 429, 503 и ошибках соединения; таймауты не повторяются; транспорт на ext-curl, заменяемый.

Проверки до запроса: размеры — число с единицей `pt`, `px`, `in`, `mm`, `cm` или `pc`; `waitDelay` — до 10 секунд; адрес — с `http(s)://`; Office-файл — ZIP-архив не больше 3,7 МБ. 429 повторяется по `Retry-After` или `retry_after_sec`. Ответы не от API (страница 404, формат Fastify, текст от прокси) разбираются по статусу; 404 — `not_found` с подсказкой про базовый адрес. Запись в файл атомарная: прерванная запись не портит прежний файл. `me()` отдаёт `userId`, `periodStart`, `periodEnd` — когда обнулится квота; `save()` возвращает путь; у каждого метода свой `timeout:`; неверные таймаут и число повторов — ошибка конструктора.

Примеры: `invoice`, `from-url`, `office`, `batch`, `quota` (для cron), `web` (без фреймворка).
